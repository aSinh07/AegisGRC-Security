SECURITY

Security & Trust

AegisGRC uses MFA-protected accounts, tenant-aware authorization, audit trails, evidence integrity controls, protected report exports and restrictive browser security headers. Assessment capabilities are intended only for explicitly authorized targets.

Responsible assurance

The platform separates evidence from conclusions and preserves human review gates. Security reports and framework mappings are support for governance decisions, not automatic certification or a guarantee of security.

Reporting a concern

Do not test this service or any third-party target without explicit authorization. Security concerns should be reported privately to the project owner through the repository or established project contact channel.
